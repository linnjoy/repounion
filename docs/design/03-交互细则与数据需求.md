## 1. 交互细则（6.4）

### 1.1 键盘快捷键规范

所有快捷键在 `<input>` / `<textarea>` 聚焦时自动屏蔽（`Esc` 与 `F5` 除外）。

| 快捷键 | 作用域 | 触发行为 | 细节说明 |
| :--- | :--- | :--- | :--- |
| `F5` | 全局 | 刷新当前工作区全部仓库本地状态 | 逐行渐进出结果；若正在刷新则忽略重复触发 |
| `Ctrl + Shift + F` | 全局 | 触发 `Fetch 全部` | 避免与浏览器默认 `Ctrl+F` 冲突 |
| `Ctrl + F` 或 `/` | 主列表 | 聚焦搜索框并全选已有文本 | 输入即时过滤，无须回车 |
| `Esc` | 全局（分层退出） | 逐层关闭当前最顶层浮层 | 优先级：确认弹窗 → 设置弹窗 → 详情面板 → 取消列表多选 → 清空搜索框 |
| `↑` / `↓` | 主列表聚焦时 | 上下移动当前高亮仓库 | 若详情面板已打开，同步切换右侧详情（防抖 `80ms`） |
| `Enter` | 主列表聚焦时 | 打开当前高亮仓库的详情面板 | 已打开时将焦点移入详情文件列表 |
| `Space` | 主列表聚焦时 | 勾选 / 取消勾选当前仓库（用于批量写操作） | 支持 `Shift + Click` 连续范围勾选 |
| `↑` / `↓` | 详情面板聚焦时 | 切换上一个 / 下一个改动文件 | 自动跨文件分组连续移动 |
| `[` / `]` | 详情面板打开时 | 跳转到上一处 / 下一处文本差异（Hunk） | 自动平滑滚动居中，并在计数器高亮当前 `n / m 处差异` |
| `1` / `2` / `3` / `4` | 详情面板打开时 | 快速切换 4 种比较方式 | `1`: 工作区vsHEAD · `2`: 工作区vs暂存 · `3`: 暂存vsHEAD · `4`: 本地vs上游 |
| `Alt + W` | 全局 | 切换「全部哨兵」与「收工检查」视图 | 便于下班前一键切换 |

### 1.2 排序与筛选规则

#### 1.2.1 主列表默认优先级排序（组内排序）
在**按来源目录分组**的前提下，每个分组内部严格按以下 8 级紧急度降序排列：

1. **有新变化**（`hasNewChanges === true`）— 优先让开发者立刻看到 AI agent 刚动过的仓库
2. **冲突 / 与远端分叉**（`conflictCount > 0 || isDiverged`）
3. **保护分支风险警告**（`isProtectedBranch && (isDirty || ahead > 0)`）
4. **有未提交改动**（`modifiedCount + untrackedCount > 0`）
5. **读取失败 / 超时**（`errorState !== null`）
6. **未推送提交**（当前分支 `ahead > 0` 或 `otherUnpushedBranches > 0`）
7. **落后于上游**（`behind > 0`）
8. **干净（已同步 / 无上游 / 游离 HEAD）**

- **同优先级次级排序**：按最后提交时间倒序（最近提交在前）；时间缺失时按仓库名拼音/字母升序。
- **反跳动防误触原则**：当用户在列表上点击单行「标记已查看」时，**不立即把该行瞬移走**，而是先褪去紫色标记，待下一次刷新或切换筛选时再重排，避免连续操作时点错下一行。

#### 1.2.2 筛选条规则
筛选芯片为**互斥单选**（全部 / 有新变化 / 有改动 / 未同步 / 冲突 / 无上游），与搜索框取**交集（AND）**：
- `有新变化`：`hasNewChanges === true`（数量为 0 时仍可保留置灰或自动隐藏，建议始终保留但置灰，方便确认“无新变化”）
- `有改动`：已修改 > 0 或 未跟踪 > 0 或 冲突 > 0
- `未同步`：当前分支 `ahead > 0 || behind > 0 || otherUnpushedBranches > 0`
- `冲突`：含冲突或分叉
- `无上游`：当前非游离 HEAD 且无 upstream
- **空分组自动隐藏**：筛选或搜索后某来源目录下匹配数为 0 时，自动隐藏该分组头；全部为 0 时展示可一键重置筛选的空状态。

### 1.3 加载、超时与错误状态处理

| 场景 | 触发条件 | 界面表现 | 恢复操作 |
| :--- | :--- | :--- | :--- |
| **逐行刷新加载** | 手动 `F5` / 按钮 / 窗口获焦 | 已完成行即刻显示新数据；未完成行保留旧数据但降透明 `0.55` + 微型加载环；顶栏显示 `x / N` | 无需阻塞用户点击已完成行看 Diff |
| **单仓 Fetch 中** | `Fetch 全部` 或单行 Fetch | 仅替换该行“远端列”为 `◌ Fetch 中...`，工作区改动列保持可读 | 完成后更新远端超前/落后数 |
| **Fetch 失败 / 超时** | 网络错误 / 鉴权失败 / 超时 | 1) 行内远端列显示红色 `⌛ 超时` 或 `✕ Fetch 失败`；2) 列表顶部出现可折叠的非阻塞汇总条 | 支持汇总条一键「重试异常项」或单行重试 |
| **本地读取失败** | 文件夹被删 / `.git` 权限错误 | 行左侧虚线红条 + 跨列错误原因 | 行右侧提供 `重试` 与 `从工作区移除` |
| **批量写操作状态漂移** | 确认执行时仓库快照已过期 | 不中断其余仓库，仅该行标为 `⊘ 已跳过（状态漂移）` 并说明具体漂移原因 | 执行完毕后用户可重新刷新并检查该仓库 |

### 1.4 动效与过渡时长规范

遵循 Windows 原生桌面工具的“干脆、零拖沓”原则，全部动效在 `@media (prefers-reduced-motion: reduce)` 下自动归零：

| 交互元素 | 动画属性 | 时长 | 缓动函数 |
| :--- | :--- | :--- | :--- |
| 列表行悬停、按钮态切换 | `background-color`, `border-color` | `100ms` | `cubic-bezier(0.2, 0, 0, 1)` |
| 详情面板展开 / 收起 | `transform`, `opacity` | `180ms` | `cubic-bezier(0.2, 0, 0, 1)` |
| 弹窗打开 / 关闭 | `opacity`, `transform: scale(0.98 → 1)` | `150ms` | `cubic-bezier(0.2, 0, 0, 1)` |
| 刷新单行出结果微闪 | `background-color` 淡入淡出 | `260ms` | `ease-out` |
| 加载旋转指示器 | `rotate(360deg)` | `900ms` | `linear infinite` |
| Diff Hunk 跳转高亮 | `box-shadow` 闪动一次 | `300ms` | `ease-out` |

## 2. 数据需求清单（6.5 供后端评估）

以下列出本设计方案中**超出交接文档 4.2 原有列举字段**，但界面交互依赖的补充数据字段（不含架构变更，仅作字段评估参考）：

| 所属模块 | 需求字段 / 能力 | 类型建议 | 用途说明 |
| :--- | :--- | :--- | :--- |
| **主列表 · Agent 新变化** | `changeSummary?: string` | `string \| null` | 悬停 `✦ 新变化` 胶囊时展示具体变化原因（如“HEAD 移动”或“工作区改动文件数变化”），帮助开发者快速判断 agent 做了什么。 |
| **主列表 · 保护分支** | `isProtectedBranch: boolean` | `boolean` | 后端按工作区规则（通配符）计算当前分支是否受保护，避免前端重复实现 glob 匹配差异。 |
| **主列表 · 逐行刷新与状态** | `rowRefreshState: 'idle' \| 'refreshing' \| 'fetching'` | `enum` | 区分行级“正在刷新本地状态”与“正在 Fetch 远端”，以及完成时间戳 `lastRefreshedAt`。 |
| **主列表 · 错误分类** | `errorKind?: 'read_failed' \| 'fetch_failed' \| 'fetch_timeout'` + `errorMessage?: string` | `object` | 区分本地读取失败、远端 Fetch 失败与超时，用于行内图标区分及顶部非阻塞汇总条归类。 |
| **收工检查视图** | `wrapUpItems`（分支粒度清单） | `Array<BranchItem>` | 按分支维度列出非当前分支上的未推送分支名、上游名、ahead 数、最新提交时间；以及 stash 摘要列表（`ref`, `message`, `age`）。 |
| **批量写操作预览** | `previewCommits: Array<{ hash: string, title: string }>` | `Array` | 预览弹窗展开某仓库时，展示即将 `push` 或 `pull --ff-only` 的提交短哈希与标题（只读确认，非历史浏览器）。 |
| **批量写操作执行** | `resultStatus: 'success' \| 'skipped_drift' \| 'skipped_invalid' \| 'failed'` + `reason?: string` | `enum + string` | 明确区分“执行时因状态漂移跳过”与“普通执行失败”，以呈现准确的解释文案。 |
| **批量切分支** | `localBranches: string[]` | `string[]` | 批量切换分支弹窗中提供选中仓库的公共本地分支建议列表，降低手输拼写错误。 |
| **图片 Diff** | `oldMeta / newMeta: { width, height, byteSize }` | `object` | 图片并排对比底部展示修改前后的像素尺寸与文件大小变化。 |
| **工作区设置** | `workspaceSettings: { protectedPatterns, sourceDirs, autoScan, excludePatterns }` | `object` | 读写工作区级配置项，用于设置弹窗持久化。 |

## 3. 范围外产品建议（6.6 独立记录，未画入主方案）

以下点子严格位于本次交接范围之外，不纳入当前 UI 实施，仅作为后续版本演进参考：

1. **「仅看 AI Agent 活跃仓」快捷过滤 / 静音名单**：对于长期挂着临时修改的实验仓库，允许开发者右键将其“临时忽略收工检查”，防止收工列表出现噪音，降低告警疲劳。
2. **自定义外部工具配置**：目前「⋯」菜单固定提供资源管理器 / 终端 / VS Code，专业开发者常使用 Cursor、Windsurf、Rider、CLion 或 Windows Terminal，后续可在全局设置中支持选择默认编辑器与终端。
3. **收工前一键复制改动摘要（Markdown）**：在收工检查视图提供「复制今日未收尾/待推送清单」，方便开发者直接贴到日报、PR 描述或发给 AI agent 继续收尾。
4. **多仓库同分支批量状态对齐提示**：当一个微服务工作区里 10 个仓库有 9 个在 `release/2.4`、唯独 1 个落在了 `main` 时，提供柔和的“分支不一致”提示。
